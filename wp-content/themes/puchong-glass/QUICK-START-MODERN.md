# ⚡ Modern Admin Panel v3.0 - Quick Start (2 Minutes)

## 🎯 Get Started Instantly

### Step 1: Login to WordPress
```
Go to: https://yourdomain.com/wp-admin
Login with your admin credentials
```

### Step 2: Access Modern Admin Panel
**Option A - Via Menu:**
1. Look at the left sidebar
2. Click "**Puchong Glass**" menu item
3. ✅ Admin panel opens!

**Option B - Direct URL:**
```
https://yourdomain.com/wp-admin/?puchong-admin=1
```

## 📞 Troubleshooting

### Not seeing admin panel?
→ Make sure you're logged in as admin
→ Try direct URL: `?puchong-admin=1`

### Styles look weird?
→ Clear browser cache (Ctrl+F5)
→ Check internet connection
→ Reload page

### Contacts not showing?
→ Check if contact form is active
→ Verify contacts were submitted
→ Try searching by date
