A premium, modern WordPress theme for Puchong Glass & Aluminium.

== Description ==

This theme is a custom conversion of a Next.js design into a native WordPress theme. It features a modern, clean aesthetic suitable for a glass and aluminium business.

Key Features:
- **Tailwind CSS**: Styled using utility-first CSS for rapid and consistent design.
- **Responsive**: Fully responsive layout that looks great on mobile, tablet, and desktop.
- **Custom Page Templates**: Includes dedicated templates for Home, About, Services, Portfolio, Contact, and FAQ pages.
- **SEO Friendly**: Semantic HTML5 structure and support for dynamic titles.
- **Lucide Icons**: Uses modern, crisp SVG icons.

== Installation ==

1. Upload the theme folder to the `/wp-content/themes/` directory.
2. Activate the theme through the 'Appearance' menu in WordPress.
3. Create pages for Home, About, Services, Portfolio, Contact, and FAQ.
4. Assign the corresponding "Template" to each page in the Page Attributes section of the editor.
5. Go to Settings > Reading and set "Your homepage displays" to "A static page" and select your Home page.

== Page Templates ==

- **Home Page**: Assign to your front page.
- **About Page**: For the About Us section.
- **Services Page**: Lists all services.
- **Portfolio Page**: Showcases projects with a filterable grid.
- **Contact Page**: Contact form and details.
- **FAQ Page**: Frequently Asked Questions.

== Development ==

This theme uses Tailwind CSS via CDN for demonstration purposes. For a production environment, it is recommended to set up a build process to compile Tailwind CSS and purge unused styles for better performance.
