**Email Address:**
```

```

**Business Address:**
```
Example: Puchong, Selangor 58000
```

**WhatsApp Link:**
```

Malaysia: 60 + 123456789 = 60123456789
```

## 📊 MANAGING CONTACTS

### Viewing Contacts
```
Dashboard → Contact List
```

### Searching Contacts
1. Type in search box: name, email, or phone
2. Results filter automatically
3. Click "Clear" to reset search

### Viewing Contact Details
1. Find contact in list
2. Click **"View"** button
3. Opens detailed form with:
   - Full name
   - Email address
   - Phone number
   - Service interested in
   - Complete message
   - Submission date & time
   - IP address

### Exporting to CSV
1. Click **"Export CSV"** button
2. File downloads: `contacts-DATE-TIME.csv`
3. Open in Excel or Google Sheets
4. Share or analyze data

### Deleting Contacts
1. Find contact in list
2. Click **"Delete"** button
3. Confirm deletion
4. Contact removed permanently
