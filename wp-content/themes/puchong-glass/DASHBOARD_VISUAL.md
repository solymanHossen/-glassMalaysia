## 🔄 User Flow Diagram

```
User visits Contact Page
         ↓
Fills out form
         ↓
Clicks "Send Message"
         ↓
AJAX submission
         ↓
    ┌────┴────┐
    ↓         ↓
 Success   Error
    ↓         ↓
Save to DB  Show error
    ↓
Send email to admin
    ↓
Show success message
    ↓
Form resets


Admin Flow:
         
Login to WordPress
         ↓
View Dashboard
         ↓
See new contact notification
         ↓
Click to view details
         ↓
Read message
         ↓
Click "Reply via Email"
         ↓
Email client opens
         ↓
Send reply
         ↓
Mark as Read
         ↓
(Optional) Archive or Delete
```

## 💫 Interactive Elements

```
Hover Effects:
├── Widget Headers: Stays gradient
├── Contact Items: Lifts up with shadow
├── Buttons: Color darkens + lift
├── Quick Actions: Lifts + shadow grows
└── Stats Cards: None (visual only)

Click Actions:
├── Mark as Read: Updates badge + removes button
├── Archive: Updates badge + hides item
├── Delete: Fades out + removes item
├── Reply: Opens email client
└── Quick Actions: Navigates to page
```

## 📊 Database Relationships

```
WordPress Users (wp_users)
         ↓
    Can manage
         ↓
Contact Submissions (wp_pg_contacts)
         │
         ├── ID (Primary Key)
         ├── Name
         ├── Phone
         ├── Email
         ├── Message
         ├── Submitted At
         └── Status


No foreign keys (standalone table)
Can be exported/backed up independently
```

## 🔐 Permission Structure

```
User Capabilities:

Administrator (manage_options)
├── ✓ View Dashboard Widgets
├── ✓ Access Contact Forms Menu
├── ✓ View All Contacts
├── ✓ Mark as Read/Archive
├── ✓ Delete Contacts
├── ✓ Export CSV
└── ✓ Receive Email Notifications

Editor
└── ✗ No access to Contact Forms

Other Roles
└── ✗ No access to Contact Forms

Public Users
└── ✓ Submit Contact Form Only
```
